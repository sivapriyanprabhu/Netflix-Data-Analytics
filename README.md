# Netflix Data Analytics Using SQL

Analyzed Netflix movies and TV shows using MySQL to identify content trends and insights.

### Key Analyses
- Movies vs. TV Shows distribution
- Missing value identification and cleaning
- Top content-producing countries
- Netflix content growth trends
- Top directors and genres
- Year-over-year content growth
- Longest-duration movies

### Tools Used
- MySQL
- SQL
- Common Table Expressions (CTEs)
- Window Functions
- Data Cleaning and Analysis
